# Экологический рентген Алматы

Интерактивный веб-атлас экологического состояния трёх районов Алматы: Наурызбайского, Алмалинского и Турксибского.

## Состав

- Интерактивная карта районов (Leaflet, GeoJSON).
- Пять направлений анализа: озеленение, качество воздуха, городской перегрев, транспортная нагрузка, отходы.
- Сравнение районов.
- Раздел «Методология» и перечень источников.
- ИИ-помощник на базе Google Gemini API.

## Технологии

HTML5, CSS3, JavaScript (ES6+), Leaflet, Chart.js.

## Структура

```
index.html

chat.css

README.md
```

## Запуск

Требуется подключение к интернету. Проект запускается через локальный HTTP-сервер:

```
python -m http.server 8000
```

Адрес: http://localhost:8000

## Настройка ИИ-помощника

Ключ Gemini API указывается в файле `chat.js`, параметр `apiKey`. В репозитории значение не задано. Ключ необходимо указать самостоятельно.

## Данные

Подтверждённые показатели по районам отсутствуют. Городские данные (отходы Алматы, 2025 год) приведены с указанием охвата. Площадь районов рассчитана по границам OpenStreetMap. Недоступные показатели имеют соответствующий статус.

## Источники

- Границы районов: akilbekov/almaty.geo.json (данные OpenStreetMap contributors, ODbL).
- Картографические подложки: OpenStreetMap, Esri World Imagery.
- Статистические и экологические данные: Казгидромет, gov.kz, stat.gov.kz, Copernicus, USGS, NASA Earthdata.

Полный перечень приведён в разделе «Источники» на сайте.
